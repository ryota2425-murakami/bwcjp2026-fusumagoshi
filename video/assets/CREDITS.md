## 声と効果音
- ナレーション・祖母・孫の声: Qwen3-TTS(Apache-2.0)で合成。実在の人の声は使っていない
- 行灯(ふすまごし・Claude)の声: AivisSpeech Engine と音声合成モデル「まお」(Aivis Project / ACML 1.0、クレジット表記は任意)。動画の行灯の台詞は、収録のときに Claude が書いた台詞をこの声で読み直したもの
- Claude のキャラ: Claude Code のマスコットへのオマージュとして、この作品のために描いた(Anthropic の公式素材ではない)。場面は HyperFrames(HeyGen、Apache-2.0)で書き出した。Pi の画面は、Raspberry Pi 5 の画面をそのまま録画した(wf-recorder)
- 電話の呼出音: 自作の合成音。ふすまの「すーっ」「トン」、柱時計、判子、郵便受け、鈴、キーボード、技術の場面のリズム(拍子木と木琴): `video/script/make_sfx.py` で数式から合成(自作)
