# SPEC ─ ふすまごし 概略 20 秒(案 A: 通話明細が書かれていく)

GOAL:    見終わった人が「祖母の声と間だけを聞き、通話中は黙り、3 つの Claude が別々に考え、電話のあとに聞き、家族には便りで届く」を一続きで言える。
OUTPUT:  HyperFrames, 1920 x 1080, 30 fps
TIME:    22.0 s x 30 = 660 frames(ナレーション 0.4〜20.3 s、結び 20.6〜22.0 s)。音楽なし。ナレーションは本人が別に録る。
LOOK:    素材は本物の画面(新しい台所の画面と家族の画面。架空の通話 S05 を流し直して 2 倍で撮った 3840x2160 の静止画)。
         地は画面そのもの(冷たい白 #f1f3f4)、墨 #14181b、帯 #1d4541。琥珀は画面の行灯の灯りだけ(足さない)。
         注目の枠: 墨 #14181b、線 3px、角丸 4px、線を引くように描く(0.45 s)。影・グロー・粒子なし。
         結び: 帯 #1d4541 を全面に、名前 Noto Sans JP 700 112px 字間 0.08em、題 Noto Sans JP 400 40px。
OBJECTS: 台所の画面(通話明細の行、間の斜線、声量 dB、行灯と灯りの強さ %、判定の 3 列)、家族のスマホ(便り)。
MOTION:  カメラ: power3.inOut 0.8〜0.9 s、寄りは最大 1.9 倍(素材は 2 倍で撮っているので粗くならない)。
         切り替え: 画面どうしのクロスフェード 0.4〜0.6 s(sine.inOut)。明細の行: 1 行ずつ段階的に出る(0.175 s ごと、イージングなし)。
         判定の列: 上から下へ 0.45 s で現れる(power2.out)、0.6 s ずつずらす。
SHOTS:
  1. 0.0–4.4   全体(1.0 → 1.12 倍、上端に固定してゆっくり寄る)。1.0 s で見守り中の画面から通話中の画面へ(行灯 62% → 5%、「電話中」に下線)。
               読ませるもの: 「通話明細」「電話中 光らない・話さない」。ナレ 1「一人で暮らす祖母の電話を、黙って聞く行灯です。」
  2. 4.4–9.6   4.4 で明細に寄る(1.4 倍)。4.9〜8.4 で祖母の発話が 1 行ずつ記帳される。6.0 で「相手の時間/祖母の声」と「間 秒」の列を枠で囲む。
               7.8 で全体に引き、8.6 で行灯の「5 灯りの強さ %」を枠で囲む。ナレ 2「聞くのは、祖母の声と「間」だけ。通話中は、光らず、話しません。」
  3. 9.6–12.8  判定の 3 列に寄る(1.75 倍)と同時に、通話後の画面へ。聞き役・反証役・まとめ役の中身が 10.2 / 10.8 / 11.4 に現れる。ナレ 3「三つの Claude が、別々に考えて、」
  4. 12.8–16.6 行灯と問いかけに寄る(1.9 倍)。13.2 で行灯が灯る(34% → 96%)。ナレ 4「電話のあとに「さっきの電話、なんだったの？」。」
  5. 16.3–20.6 家族の画面へクロスフェード。スマホの便りに寄る(1.18 → 1.26 倍)。19.0 で「話しかけ方の例」を枠で囲む。ナレ 5「家族には、警報ではなく、夕方の便りを届けます。」
  6. 20.6–22.0 帯の色が左から画面を覆い、「ふすまごし」と「離れていても、ふすま一枚向こうに。」(README の題)が置かれて止まる。
BANNED:  暗い背景に小さな要素を浮かべる / グロー・粒子 / 字幕でナレーションをなぞる / すべてがフェードして上へ滑る / 角の飾り・HUD / 画面にない数字や主張を足す / 画面を作り直して描く(本物の画面だけを使う)
QA:      f0(本物の画面が全面に出ている)、f45(行灯が消えかけ)、f190(明細が途中まで・間の枠)、f265(全体・行灯 5% に枠)、
         f340(判定 3 列のうち 2 列目まで)、f430(行灯が灯り問いかけ)、f570(便りと話しかけ方の例に枠)、f650(結び)。
