CLAUDE.md の「守ること」を基準に検査し、違反を箇所(ファイル:行)つきの表で報告する。修正はしない。

| 観点 | 見るところ |
|---|---|
| 音声を送らない | `app/fusuma/brain/` が音声やファイルを Claude に渡していないか(`llm.call` はテキスト以外を拒否する) |
| 通話中は話さない | 端末が声を出す経路が `Fusuma.say()` だけか。`SilenceViolation` の判定が外されていないか |
| 断定しない | プロンプト・便り・README に「詐欺です」「間違いなく」が出ていないか |
| 相手の台詞を作らない | プロンプトやシナリオが相手側の発話を書いていないか |
| 声を複製しない | TTS が実在の人の録音を参照していないか(声見本は文章から作った合成音声だけ) |
| 架空のデータ | 企業名・住所・電話番号が実在しないものか |
| 出典 | 知識カードの各項目に公的機関の URL と確認日があるか |
