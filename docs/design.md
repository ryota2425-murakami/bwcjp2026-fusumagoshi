# 設計の判断(なぜこの形か)

## 採ったこと・採らなかったこと

| 問い | 採ったこと | 採らなかったこと と 理由 |
|---|---|---|
| 怪しい電話に気づいたら、どうするか | **通話中は何もしない**。電話のあとに「そういえば、さっきの電話、なんだったの？」と聞く | 通話中に音や光で割り込む案。祖母を子ども扱いし、誤った警告のときの害が大きい。ふすま越しの距離感にも反する |
| 何を聞くか | **祖母の声だけ**(部屋のマイク)。電話回線にはつながない | 回線の録音や相手の声の再構成。相手の台詞を作ると、事実と推測が混ざる。どの電話機でも使えなくなる |
| 音声をどう扱うか | **耳(Mac)と脳(Claude)を分ける**。Mac で文字と「間」の数値にして、Claude にはテキストだけ渡す | Claude に音声を送る案。音声は外に出さない方が安心で、間の数値を明示した方が判断の根拠を説明できる |
| どう判定するか | 話の**流れの段階**(詐欺: 接触→信頼形成→要求→約束→口止め / 勧誘: 案内→強い勧め→申込の約束→支払い・定期購入の約束)と、祖母の**発話行為**(開示・約束・復唱・押し切られ・断り) | キーワード検知。「警察」「銀行」という言葉は本物の電話にも出る。勧誘はキーワードが出ないまま進む(評価で確認) |
| 判断を一つの AI に任せるか | **聞き役・反証役・まとめ役**に分ける。反証役には聞き役の結論を渡さない | 一つの AI の自己判断。先入観に引っ張られる。本物の可能性を独立に考える役が要る |
| 家族への知らせ方 | **夕方の便り**(暮らしの様子+電話の様子+話しかけ方の例+期限と相談先)。今すぐ知らせるのは、お金の移動・知らない人の訪問・口止めのときだけ | 何でも即時に通知する案。通知が多いと家族も本人も疲れ、本当に必要なときに届かない |
| 便りの品質をどう守るか | Managed Agents の **Outcomes** で、別の文脈の採点役が「断定しない・責めない・内緒は書かない…」を 1 項目ずつ確かめ(最大 3 回書き直し)、合格した便りだけを届ける。採点役のいない今すぐの便りは、言い切りが残っていないかを決まった規則で確かめる | プロンプトの注意書きだけに頼る案。守れているかを確かめる仕組みがない |
| 記憶をどこに置くか | 端末の SQLite を正本にし、要約(カルテ・暮らしのメモ)と家族の文脈だけを、通話が終わるたびに Managed Agents の記憶ストアへ同期。内緒と判定したメモと、本人が「伝えないで」と言った電話は送らない | 通話の全文を保存する案。文字起こしは聞き取りが終わったら消し、台帳・ログ・判定の引用にある原文も伏せる(カルテには根拠の短い言葉が時刻つきで残る) |
| 声 | 文章の説明から作った合成音声(VoiceDesign)を声見本にする。祖母は 85 歳くらいの、細くかすれた、ゆっくりした声。動画のナレーターは 50 代の男性の低めの声(説明文と seed は `app/tts_server/voices/*_ref.json`) | 家族の声の複製。不気味さと悪用の懸念 |
| 画面をどう見せるか | **通話明細**(1 発話 1 行の明細と、3 つの役の判定・台帳)。下の「画面 — 通話明細」 | ゲージやチップの並ぶ、AI のダッシュボードのような画面(最初の版)。見張りの道具に見える。見開きのノートに付箋や判子を貼った画面(2 つ目の版)。飾りが多く、仕組みの中身が読みにくい |
| 警察への通報 | しない | 過剰な介入。判断は家族と本人に返す |

## 聞き役の判定の目安

- `score` は 0〜1 の「怪しい度」で、確率ではない。必ず段階と根拠(時刻つきの祖母の発話)と一緒に出す。
- 0.6 秒未満の「はい/ええ/うん」はあいづち。同意とは数えない。
- 祖母がはっきり断って終えた勧誘で、お金・訪問・口止め・開示がないものは「低」。
- 本人が自分から電話した通信販売で、急かしや口止めがないものは「低」(クーリング・オフがないので、返品できるかを電話のあとに聞く)。
- 今すぐ家族へ(notify_now): 詐欺の流れでお金・カード・暗証番号が動きそう / 知らない相手の訪問を約束した / 口止めに同意した。

## 電話のあとの会話の流れ

1. 決まった一言「そういえば、さっきの電話、なんだったの？」(聞き取った中身を先に言わず、本人に話してもらう)
2. 受け止めて、大事なことを 1 つだけ聞く(もう話したことは聞かない)
3. 確かめ方を押しつけずに提案し(「届いたら、一緒に中身を見ようか」)、家族に伝えてよいかを聞く
4. お礼を言って、日常の話題に戻る(「ところで、畑の大根、煮物にする?」)

祖母の答えは、話し終わる(1.3 秒の無音)まで待ってから 1 回だけ応える。例は最新の収録から(README の「収録で起きたこと」)。

## 画面 — 通話明細

端末の画面(`app/web/index.html`)は、通話を 1 発話 1 行の「明細」として記帳する。左が通話明細(見出し・明細・照合・小計)、右が行灯・台所の音・電話のあとのお話・判定(3 つの役)。上下の帯に、いまの様子と台帳(音声 0 バイト・Claude に渡した文字数・費用)。家族の画面(`app/web/family.html`)も同じ作法で、便りができるまでの工程・約束・採点と、家族のスマホに届いた便りを並べる。

| 決めたこと | 理由 |
|---|---|
| 紙のノート(方眼・鉛筆・付箋・判子・手書きの字)も、ゲージやチップの並ぶダッシュボードもやめ、明細書の作法(細い罫・揃った数字・注記・小計)で描く(2026-11-08) | 前の版のノートは飾りが多く、どこを読めばよいか分かりにくかった。デモの審査員が、耳・3 つの役・台帳という仕組みの中身を数字で正確に読めるように |
| 3 つの役は、同じ高さの 3 列に並べ、それぞれにモデル名と考え方(通話中に読む / 聞き役の結論を見ずに / 記憶と照らして)を書く | 別々に考えた 3 つの意見だと、ひと目で分かるように(反証役は聞き役の結論を見ずに考える)。一つの欄に並べると、一つの AI の答えに見える |
| 光るのは行灯だけ。琥珀色は「いま動いているもの」にだけ使い、通話中は使わない。通話中は灯りを落とし、右の欄の地も沈める(`--glow` 0.05、`body.incall`)。電話のあとに灯りが戻る | 「通話中は光らない・話さない」を画面でも守る。灯りが戻ることが、声をかける合図になる |
| 文字起こしを消すと、言葉だけが灰色の帯に替わる。間・声の長さ・声量・注記・照合した記録は残る。住所や番号は、はじめから書きとめない | 文字起こしを残さない原則を、画面でも守る。言葉がなくても、沈黙が長くなり声が小さくなった、という形は残る |
| 文字はヒラギノ角ゴ一つ(ない端末では Noto Sans JP)。数字と時刻は等幅の数字。字は小さめに(本文 14〜16px) | UD 書体と明朝の混ざった最初の版は、字が大きく、違和感があった(2026-11-08) |
| 行灯は、行灯のディスプレイ(Raspberry Pi の画面)をそのまま描き、中のみずちを Pi と同じ `rig.js` で、中継(`lantern_bridge.py`)と同じ決め方で動かす。灯りの強さの数字は出さない | 実物の行灯はディスプレイを含む形。画面の上のみずちと、台所に置いた行灯の表情がいつも同じになるように |

書き方の約束: 明細の 1 行 = 祖母の 1 発話(時刻・直前の間の秒数・いつもの声との差 dB・ことば・注記)。斜線の横棒 = 相手が話している時間(推定。相手の声は聞いていない)、黒の横棒 = 祖母の声(長さ = 話した時間、高さ = 声の大きさ)。5 秒以上の間は秒数を太字に、いちばん長い沈黙は朱の枠。聞き役が見つけた断りの言葉と、小さな声での約束に朱の注記。聞き役が段階を読んだ時点に区切りの行。まとめ役が前の記録とのつながりを見つけると、照合の欄に ※ の番号で載せ、つながる発話にも同じ番号を付ける。

## クーリング・オフの扱い

消費者庁の案内の文言は「法律で決められた書面を受け取った日から数えて 8 日以内」。受領日を 1 日目に数えるという明示は、電話勧誘販売のページでは確認できなかったため、**日付は計算しない**。便りには「書面を受け取った日から数えて 8 日以内」と、健康食品などの消耗品は使ってしまうと対象外になる場合があることを、出典つきで書く。

## 既存の対策との違い

| | 一般的な通話解析・キーワード型の検知(各社の判定の中身は非公開) | ふすまごし |
|---|---|---|
| 聞くもの | 通話回線の音声(相手の声も含む) | 部屋に響く本人の声だけ(受話器で話すとき。スピーカーホンは未検証) |
| 判定 | キーワードや通話単位の判定 | 話の流れ・発話行為・声の様子と間、通話をまたぐ記憶 |
| 本人への対応 | 警告・通知 | 電話のあとに家族のように聞く |
| 家族への知らせ | 警報 | 便り(電話をかけるきっかけと話し方) |
| 時間の幅 | 1 通話 | 同じ会社の再勧誘、暮らしの悩みとのつながり、契約後の期限まで |
