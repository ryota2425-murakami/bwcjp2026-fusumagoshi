# ふすまの中の Claude — Raspberry Pi の画面

手製の小さなふすまの中に、Raspberry Pi 5 と小さなタッチ画面を入れます。画面にはキャラ「みずち」が住んでいて、Mac(耳と脳。脳は Claude)からの合図で表情を変えます。電話のあいだは画面ごと暗く沈んで静かにし(話さない)、電話のあとは跳ねて話し、さわると照れて笑います。

みずちは、ウーパールーパーの親戚のような小さな生きものです。Claude Code のマスコットの絵づくり(平たい色・丸い形・シンプルな暗い目・ほお紅)をまねて、この作品のために描いた別の生きもので、Claude Code のマスコットそのものでも、Anthropic の公式の素材でもありません。頭の両脇にえらの房、ひれのような尾、前足 2 本と後ろ足 2 本があります。

もとのキャラは作者に「Claude のキャラに似すぎ」と言われたので、別の生きもので、絵づくりと雰囲気はまねる形に作り直しました(経緯は下の「みずちができるまで」)。

## 役割は 2 つ

| 役割 | 置き場所 | 受け取る合図 |
|---|---|---|
| `kitchen`(既定) | 祖母の台所。端末の「顔」 | 気分(見守り/通話中/電話のあと/聞いている/便り/考え中)、通話中の 2 つの数(あやしさ・聞きたさ。0〜1)、話す長さと口の開き、返事が来たときのうなずき |
| `family` | 家族の机の上 | **便りが届いた合図と、つながっているかの確認(5 秒ごと)だけ**。電話中かどうか、話しているかどうかは送らない |

家族の机の Pi に「いま電話中」を出すと、見守りではなく見張りになります。だから family には、夕方の便りが届いたことしか渡しません。役割は Mac 側が IP で決めます(`--family` に入っている Pi は、kitchen を名乗っても family。Pi のほうから名乗れるのは、狭める向き(kitchen → family)だけ)。

## しくみ

```
Mac  端末サーバー(127.0.0.1:8780、Mac の中だけ)
      │  /ws(Mac の中から購読)
      ▼
     lantern_bridge(:8781、許可した Pi だけ)
      │  気分の名前・秒数・口の開き(0〜1 の数列)・視線(数値)だけ。文字は一文字も送らない
      ▼
Pi   Chromium のキオスク(file:// の kiosk.html + rig.js)
```

- **端末サーバーはこれまでどおり Mac の中だけ**で聞きます。中継(`app/fusuma/lantern_bridge.py`)が Mac の中からその /ws を購読し、合図に置き換えて、許可した Pi にだけ流します。
- 口の動きは、話す文のモーラ数から Mac 側で作った 0〜1 の数列だけを送ります。文そのものは送りません。
- Pi からは「さわられた」だけを受け取り、ログに残します。
- テスト(`app/tests/test_principles.py`)で、話した文・文字起こし・便りの本文が合図に一文字も入らないこと、family に便りの合図しか届かないことを確かめています。

## キャラは 1 つのファイル

`app/web/lantern/rig.js` は、**時刻と状態だけから 1 枚の絵を描く関数**です(`rig.render(t, state)`)。乱数は時刻から作り、前のフレームを覚えません。だから同じ rig.js を、Pi のキオスク(実時間で動かす)と、動画(HyperFrames が 1 フレームずつ好きな時刻に飛んで書き出す)の両方で使えます。

| 気分 | 演技 |
|---|---|
| 見守り | ゆっくり息をする。ときどき瞬き、ときどきよそ見、足をとんとん |
| 通話中 | 小さく息を吸ってから、低く座って目を閉じ、手をひざの上に。画面ごとほとんど黒まで沈む。沈んだまま 2 つの数に反応する(下の「通話中の 2 つの数」) |
| 電話のあと | 縮んで、伸びて、跳ねる。口は話す長さと口の開きに合わせて動く。話しかける順番を待つあいだは、聞きたさ(ask)でそわそわする |
| 聞いている | 首をかしげ、手を耳に。返事が来たら一度うなずく |
| 便り | 小さな手紙を胸に抱えて、えらそうに跳ねる。少しして空へ放る |
| さわられた | びっくりして跳ね、くすくす笑う(さわるたびに 3 通りから変わる) |
| 考え中 | 見上げて、手であごをとんとんする。頭の上で点が 3 つ跳ねる。Mac が Claude の返事を待っているあいだと、電話のあとの判定が走っているあいだに出る |

気分は 7 つです。

見守りのときに、Mac につながらない状態が 20 秒続くと、うとうとします。夜(22 時〜6 時)も少し眠そうになります(`query.txt` に `night=0` で止める)。さわると、9 秒ほど目を覚まします。

## 実機での速さ

Raspberry Pi 5 / Chromium 142 / 1280×720 で、Chrome DevTools MCP を Pi の Chromium(SSH で Mac に出した remote debugging)につないで測りました。

| 項目 | 値 |
|---|---|
| 6 秒間のフレーム | 360 |
| フレーム間隔 p50 / p95 / 最大 | 16.7 / 16.7 / 16.8 ms |
| 20 ms を超えたフレーム・長いタスク | 0 / 0 |
| SVG の要素数 | 46(もとのキャラのとき) |

測るときは、性能の結果を外へ送らない設定(`--no-performance-crux --no-usage-statistics`)で動かしています。上の表は、もとのキャラのときに実機で測った値です。みずちの rig は、SVG 58 要素・1 回の描画 約 0.09 ms、同じ `render(t, state)` の契約で、契約の確認(時刻だけから描く)は通っています。

## 通話中の 2 つの数

通話中、みずちは暗いまま話しませんが、Mac が送る 2 つの数(どちらも 0〜1。文字は送らない)で小さく動きます。中継(`app/fusuma/lantern_bridge.py`)が `{"type":"uneasy","sus":x,"ask":y}` の形で送ります。family の役割には送りません。

| 数 | 意味 | 元にするもの | 動き |
|---|---|---|---|
| `sus` | あやしさ | 通話中の聞き役の危険度(低/中/高)と点数 | ときどき目を細めて電話のほうをのぞく。えらがぴくぴくする |
| `ask` | 聞きたさ | 聞き役が聞きたいと思っていることの数 | 手が口もとでそわそわし、ほおがふくらみ、尾を振る |

暗い画面は、ほんの少し明るくなるだけです。電話のあと、話しかける順番を待つあいだも、`ask` でそわそわします。原則のテスト 29 件は、これを足したあとも通っています。

## みずちができるまで

Opus の設計役 3 体が、別々の生きものを並行で作りました(a 小さな丸い獣、b ひよこ、c ウーパールーパー)。Opus の審査役 2 体が、美術の目と、動きと実装の目で独立に見て、2 体とも c を選びました(合計点 c 96・b 91・a 87)。Opus の仕上げ役が審査役の直しを入れ、Sonnet の検証役が rig の契約を確かめました。最終の rig は SVG 58 要素・1 回の描画 約 0.09 ms で、同じ `render(t, state)` の契約を守り、契約の確認は通っています。

## 会話デモ

`app/fusuma/talk_demo.py`(`scripts/talk.sh` で動かす)は、電話の見守りとは別の、みずちと話すデモです。Mac のマイク → Silero VAD → whisper.cpp → Claude Sonnet 5.5(短い返事) → AivisSpeech の声(Mac のスピーカー)と流れます。

- 誰かが話しているあいだ、Pi は「聞いている」になり、短い間でうなずきます。Claude が考えているあいだは「考え中」。そのあと口を動かして話します。
- `--idle` 秒(既定 40)だれも話さないと、みずちのほうから短い問いかけをします。答えがないまま続けては 2 回まで。だれかが話せば数え直します。
- Pi へ送るのは、気分の名前・秒数・口の開きだけです(文字は送らない)。

## 実機のデモ電話(P01)

架空料金請求の電話を、実機の Pi で通しました。デモ専用で、評価の 15 通話には入れていません(`demo_only`)。

- 電話の相手の声は、警視庁の YouTube「スマホ防犯教室 オンライン型講座 架空料金請求詐欺編」(https://www.youtube.com/watch?v=yL9rZI2qmFc)の再現ドラマ(被害者編、3:14〜)から、詐欺役の声だけを切り出したものです。祖母の台詞は、いつもの祖母の声で合成し、高齢の女性が、ゆっくりためらいながら話す台詞に書き直しました。`app/scripts/synth_police.py` で作ります(耳に入れるのは、祖母の声と電話の音だけ。動画・スピーカー用には、受話器から漏れる相手の声も重ねてある)。
- 警察の音声はリポジトリに入れていません。公開する動画に使うには、警察の許可が要ります。
- 動かし方: `INPUT=virtual bash scripts/live.sh` を起動して、`/api/play` に `{"id":"P01"}` を POST します(録画は `record_demo`)。
- 結果: 通話中の危険度は 中(0.55)→ 高(0.85)、最終は 高(0.92)。反証役の検討をして、動きは「今すぐ」(家族にすぐ知らせた)。電話のあと、みずちは「そういえば、さっきの電話、なんだったの?」と聞き、「行く前に、ケンタと一緒に、確かめてみない?」と続けました。祖母は「じゃあ……やめておくわ。孫に、電話してみるね。」と答えました。この回の費用は 約 $0.17 です。
- `scripts/phone_sim.py` は、人が祖母の台詞を声に出して読むための道具です。Mac から呼出音・電話の相手の声・受話器を置く音を流し、相手が話している区間は耳を止めて「受話器を耳に当てている」状態を再現します。`--guide` を付けると、吹き替え用の見本動画を全画面で同期して流します。

## 動かし方

```bash
# Mac: 中継(台所の Pi は --allow、家族の机の Pi は --family)
cd app && ../.venv/bin/python -m fusuma.lantern_bridge --allow <Pi の IP>
# Mac: Pi に配って、自動起動を登録し、キオスクを再起動(SSH は鍵か、先に開いた接続を使う)
PI=pi@<Pi の IP> bash scripts/deploy_pi.sh
# 配線の確認(Mac の中からだけ): 合図を手で送る
curl -X POST http://127.0.0.1:8781/test/after
```

- Pi は家の Wi‑Fi で Mac につながります(ケーブルは要りません)。`deploy_pi.sh` は `PI=pi@<Pi の IP>` で宛先を受け取ります。
- キオスクは `~/.config/autostart/fusuma-lantern.desktop` から起動します(デスクトップはそのまま、上に全画面で出る)。
- 中継先は `~/fusuma-lantern/bridge.txt` に 1 行で書きます(`deploy_pi.sh` が、この Mac の名前.local と IP から書く。`BRIDGE=ws://…` で変えられる)。
- `~/fusuma-lantern/role.txt` に `family` と書くと家族の机の役割、`query.txt` に `night=0` と書くと夜もうとうとしません。
- 録画のときのイベントを流し直す(Claude は呼ばない): `lantern_bridge --replay <timing.json> --replay-from <秒>`

## カメラ

AI カメラ(IMX500)は動きます(`rpicam-hello --list-cameras`、picamera2 とも確認済み)。ただし今回は使っていません。使うとしても、人がいるかどうかを Pi の中(カメラの上)で数えるだけにして、映像は Pi の外に出さない予定です。

## 声

行灯(Claude)の声は、ローカルで動く AivisSpeech Engine の「まお」(おちつき)です(ACML 1.0)。Mac の TTS サーバーが、行灯の声だけをこのエンジンで読みます。エンジンが止まっていれば、これまでの Qwen3-TTS の声に戻ります。

エンジンは [AivisSpeech-Engine の配布物](https://github.com/Aivis-Project/AivisSpeech-Engine/releases)(macOS arm64)を展開して `~/video-as-code/engines/aivisspeech` に置くと、`scripts/services.sh start` が一緒に起動します(場所は `AIVIS_ENGINE_DIR` で変えられる。初回は既定のモデルを取りに行く)。声を変えるときは `FUSUMA_LAMP_STYLE`(話者のスタイル ID)、使わないときは `FUSUMA_LAMP_ENGINE=`(空)。
