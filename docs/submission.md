## 概要(約 200 字)
祖母が電話の勧誘で高額な商品を買わされたことが出発点です。ふすまごしは、一人で暮らす高齢者の電話を、本人の声だけ黙って聞く台所の行灯です。通話中は光らず話さず、Mac の中で声と「間」を読み、役割を分けた Claude(聞き役・反証役・まとめ役)が流れを判断します。電話のあとに「さっきの電話、なんだったの?」と家族のように聞き、夕方には離れた家族へ、電話をかけるきっかけと話し方を届けます。

## Claude の使い方
- 役割ごとにモデルと機能を選んだ。通話中に何度も呼ぶ聞き役は Claude Haiku 5.5 + 構造化出力。本物の可能性を検討する反証役は Claude Sonnet 5.5 で、聞き役の結論を渡さず、公的機関など(消費者庁・警察庁・国民生活センター・全国銀行協会)の知識カード 21 枚を search_result で渡して Citations で出典を付ける。まとめ役(Sonnet 5.5)は記憶と照らして「黙る/夕方/今すぐ」を決め、抑えた理由を残す。今すぐの便りは Opus 5.5。Sonnet・Opus は server-side fallbacks つき。プロンプトキャッシュが効いた回の評価の実費は、1 回(15 通話)約 $0.383(キャッシュがなかった場合の換算は $0.844〜$0.888)。最終の評価 4 回の実費は合計 $1.68(キャッシュを書く 1 回目が $0.5341)。端末の画面(台所の画面・通話明細)では、3 つの役の判定を同じ高さの 3 列に並べ、モデル名と考え方を添えて、別々の意見だと分かるようにした。
- 夕方の便りは Claude Managed Agents。記憶ストア(端末が通話のたびに同期するカルテと暮らしのメモ)・スキル(便りの書き方)・毎日 18:00 の定期実行・Outcomes(「断定しない・責めない・内緒は書かない」のルーブリックを別の文脈の採点役が確かめ、最大 3 回書き直す。合格した便りだけ家族に届く)を使い、`ant apply` でファイルとして管理した。最新の収録では、採点役が 1 回目に「…合計は約440字になる。400字を超えている。」と書き直しを求め、2 回目「本文の合計は約 300 字で、400 字以内。」で合格した。採点の記録は同梱しており、家族の画面にも採点役のことば(書き直し → 合格)を出す。
- 音声は Mac の外に出さない。Claude に渡すのはテキストだけ(祖母の発話と声・「間」の数値、家族の文脈、過去のカルテ、暮らしのメモ)。送った中身は台帳に残り、画面の足もとには送った量(音声 0 バイト・文字数・費用)を出す。聞き取りが終わると、その通話の分は文字起こしと一緒に伏せ、画面からも祖母の言葉だけを消す(声の線・間・数字は残る)。内緒と判定したメモは、記憶ストアにも便りにも出さない。
- 開発は Claude Code が中心。原則に反するコード(脳に音声を送る、`Fusuma.say()` を通らずに話す経路、実在しうる電話番号、内緒のメモの取り出し)を止める PreToolUse フック、原則のテスト 27 件(Claude API を呼ばない)、プロンプトを変えたら小さな評価を回す PostToolUse フック(既定では知らせるだけ)、監査役・評価係・シナリオ作者・知識カード作者のサブエージェント、提出前の最終レビューのワークフロー(6 観点を別々のエージェントが調べ、別のエージェントが 1 件ずつ反証を試みる。85 件中 80 件が確かめられ、直した)、原則のスキル、通話カルテを引く MCP サーバー、claude-api スキル、claude-code-video-toolkit(動画)。
- 評価: 架空の 15 通話 × 4 回で、本物の電話 5 本への誤警報 0/20(比較用のキーワード検知は 8/20)、怪しい電話 8 本の見逃し 0/32(同 12/32)、動き(黙る/夕方/今すぐ)60/60、危険度の判定(低/中/高)60/60。祖母の声を 85 歳くらいの細くかすれた声に作り直し、15 通話を合成し直して、「いつもの声」も測り直してから流した。台本は作者が書いたもので、統計的な主張はしない。
